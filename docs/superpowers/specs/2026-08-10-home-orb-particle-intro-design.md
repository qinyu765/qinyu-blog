# 首页月球粒子开场设计

## 目标

将首页首屏改造成 P3R 海报式错层构图：页面打开时，月球位于视口中部略偏右，白色粒子组成的小写 `lin` 锚定在月球中部并轻微浮动；向下滚动一屏的过程中，月球平滑回到当前右上角位置，`lin` 跟随月球移动并在月球附近轻柔消散。动画结束后恢复现有内容阅读节奏。

## 视觉与布局

- 首页桌面首屏高度约为一个视口，不锁定滚动、不做滚动吸附。
- 月球起点位于约 `58vw / 45vh`，保持中部略偏右；终点复用当前 `top: -18vh`、`right: -18vh`、`70vh` 尺寸的右上角构图。
- 简介卡片位于左侧中段，精选文章卡片位于右下并跨压月球边缘；两张卡片保持实色半透明面板和硬边偏移阴影，不增加发光。
- `lin` 使用现有 Anton 展示字体的小写字形作为粒子采样轮廓。粒子主色为冷白 `#F0F0F0`，少量层次色使用灰蓝白 `#CBD6E2`；不使用青色荧光、不加 `text-shadow`、`drop-shadow`、模糊光晕或 screen 混合。
- 月球继续保留现有的柔和环境亮度，因为它属于背景天体本身；控件、文字、卡片与状态标记不使用霓虹式外发光。
- 月球不是整张合成图同步浮动：月面与 `lin` 作为视觉核心同频漂移，遮罩层使用更慢且错开的相位反向轻移，外晕以最慢周期独立呼吸。各层相对位移限制在月球直径的约 `1%–2%`，只改变层叠关系，不允许露边或彼此脱节。

## 滚动叙事

- `0%`：月球位于中部略偏右，`lin` 完整位于月球几何中心；月球与文字共享轻微上下浮动。
- `10%–30%`：月球开始向右上移动；`lin` 保持居中，字形边缘的粒子开始松散。
- `30%–70%`：粒子依据稳定的随机方向在原字形附近小幅漂移并逐渐透明，不形成独立拖尾；月球持续归位。
- `70%–100%`：月球到达当前右上角状态，月心只短暂保留稀疏白色粒子，随后完全透明；`Recent Logs` 成为主要内容。
- 页面反向滚动时按同一进度可逆恢复；刷新在滚动位置或通过 `#about` / `#favorites` 进入时，场景直接同步到实际滚动进度，不从开场强制重播。

## 实现架构

- 保留 `BackgroundEffect` 的底色、噪声和水波纹，将月球视觉拆到独立客户端场景组件中；非首页仍渲染现有右上角静态/漂浮月球。
- 首页大屏场景由外层“滚动位移容器”和多组内层“环境浮动层”组成，避免 GSAP 位移与 CSS 浮动互相覆盖 `transform`。月面与粒子画布共享约 `8s` 的核心漂移；遮罩使用约 `12.5s` 的错相漂移；外晕使用约 `17s` 的低幅度位移、缩放和透明度呼吸。
- Canvas 2D 在离屏画布等待字体可用后绘制 `lin`，按自适应间距采样非透明像素，生成确定性的粒子初始坐标和漂移向量；可见画布按设备像素比渲染并限制最大 DPR。
- GSAP ScrollTrigger 只在首页且视口宽度至少 `1024px` 时加载，以 `scrub` 时间线把一屏滚动进度映射到月球位置/尺寸和粒子消散进度；场景不 `pin` 页面。
- 小于 `1024px` 的设备直接使用当前右上角月球状态，不创建粒子画布。`prefers-reduced-motion: reduce` 同样直接进入归位状态。
- 动画循环仅在首页首屏相关区间运行；场景不可见或粒子完全透明后停止 Canvas 绘制，并在卸载时清理 ScrollTrigger、监听器和动画帧。

## 去除荧光反馈

- 删除首页精选文章卡片悬浮时的青色模糊外圈，仅保留清晰的边框颜色变化和轻微位移反馈。
- 清理站内 UI 中同类的 `0 0` 发光阴影：About 状态点与进度条、文章页装饰菱形、博客列表加载标记改为平面颜色或硬边阴影。
- 保留导航 Logo 的黑色投影、面板 `backdrop-blur`、斜切按钮的硬边偏移阴影，以及月球/水波背景的低透明环境亮度；这些效果用于层次或可读性，不属于交互霓虹光晕。

## 失败与降级

- Canvas、字体采样或 GSAP 初始化失败时，只显示现有右上角月球和正常首页内容，不阻塞页面交互。
- 页面尺寸变化时重算月球路径和粒子字形；重算前保持最近一帧，避免闪回起点。
- 粒子画布设置 `aria-hidden="true"` 且不接收指针事件；真实内容和链接继续由 DOM 提供。

## 验收与验证

- 桌面首屏初始状态、30%、70% 和 100% 滚动位置与已确认分镜一致，`lin` 始终位于月球中部并随月球移动。
- 月面、遮罩与外晕交错浮动，周期和相位不同但层间不脱节；`lin` 与月面核心保持同步。
- `lin` 为白色/灰蓝白粒子，无青色荧光、模糊光晕或拖尾；精选文章悬浮不再出现青色外发光。
- 反向滚动、刷新在中途、锚点进入、窗口缩放均保持正确进度，无跳回或重复初始化。
- 小屏和减少动画模式不初始化粒子动画，直接显示当前右上角月球。
- 运行 lint、类型检查、测试和生产构建；在桌面与移动视口做首屏、滚动完成态和悬浮态截图对比，并检查控制台无错误。

## 借鉴来源

- [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)：使用 `scrub`、响应式匹配和刷新机制协调滚动进度。
- [Codrops：Interactive Typography Effects with HTML5](https://tympanus.net/codrops/2011/11/09/interactive-html5-typography/)：借鉴离屏 Canvas 绘字并按像素采样粒子坐标的基本方法。
- [Codrops：3D Typing Effects with Three.js](https://tympanus.net/codrops/2022/11/08/3d-typing-effects-with-three-js/)：借鉴粒子文字的字形组织与渐散观感，但本项目采用更轻量的 Canvas 2D。
- 未采用 tsParticles：其 `text` shape 让单个粒子绘制成文字，并不能直接让粒子组成目标字形。
